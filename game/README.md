# BoomVerse: อาณาจักรศิลา — browser prototype

ต้นแบบแรกของเกมสร้างอาณาจักรไทยโบราณแบบสมมติ เล่นได้ทันทีในเบราว์เซอร์

## เกมเพลย์ในต้นแบบนี้

- คลิกช่องทรัพยากรเพื่อเก็บไม้ ข้าว และศิลา
- สร้างเรือน ชาวนา และค่ายนักรบ
- เพิ่มประชากรและกำลังทหาร
- กดออกศึกเพื่อจำลองการขยายดินแดน
- เป้าหมายแรกคือสร้างอาณาจักรให้มีชื่อเสียง 100

เปิด `game/index.html` โดยตรง หรือเข้าผ่าน GitHub Pages ที่ `/BoomVerse/game/`
