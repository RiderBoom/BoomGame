# อาณาจักรศิลา — game direction

## Identity

เกมสร้างอาณาจักรและเอาตัวรอดในโลกไทยโบราณสมมติ ใช้แรงบันดาลใจจากภูมิประเทศ สถาปัตยกรรม ภาษา ศิลปะ และการเมืองในภูมิภาค แต่ตัวละคร เมือง อาณาจักร และเรื่องราวเป็นต้นฉบับของ BoomVerse

## Core loop

สำรวจ → เก็บทรัพยากร → สร้างชุมชน → ดูแลผู้คน → ฝึกกองทัพ → เจรจาหรือทำสงคราม → ขยายอาณาจักร

## Design guardrails

- นำเสนอความขัดแย้งและแรงงานบังคับอย่างมีผลกระทบ ไม่ทำให้ความโหดร้ายเป็นรางวัลอย่างเดียว
- ผู้เล่นมีทางเลือกด้านการปกครอง เช่น เชลยศึก แรงงานรับจ้าง การเกณฑ์แรงงาน หรือการปลดปล่อย
- ทุก asset, เพลง, ตัวละคร, แผนที่ และโค้ดต้องสร้างใหม่หรือมี license ที่ตรวจสอบได้
- ไม่ใช้ชื่อหรือองค์ประกอบเฉพาะจากเกมอื่น
