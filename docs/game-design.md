# อาณาจักรศิลา — third-person survival direction

ต้นแบบนี้เปลี่ยนแกนเกมจากการวางแผนแบบ 2D เป็นเกม survival มุมมองบุคคลที่สามในโลกไทยโบราณสมมติ

## Prototype controls

- WASD: เดิน
- Shift: วิ่ง
- ลากเมาส์: หมุนกล้อง
- คลิกฉาก: ทดลองโจมตีด้วยหอก

## Next systems

1. เก็บทรัพยากรและคราฟต์
2. สร้างที่พักและค่าย
3. สัตว์ป่าและศัตรู AI
4. ระบบ hunger, health และ weather
5. multiplayer และอาณาจักรคู่แข่ง

ระบบทั้งหมดจะพัฒนาใหม่เพื่อ BoomVerse โดยใช้เพียงแนวคิดของ survival game เป็นแรงบันดาลใจ ไม่ใช้ asset หรือโค้ดจากเกมอื่น
